# 🧩 PKI PQC Rust

Projet d’apprentissage : implémentation progressive d’une PKI en Rust.

---

## 🚀 Fonctionnalités

- Génération de clés (Ed25519)
- Signature de messages
- Vérification de signatures
- Création de CSR
- Vérification de CSR

---

## 🎯 Objectif

Comprendre et construire une PKI from scratch, avec une évolution vers le post-quantique (PQC).

---

## ⚙️ Utilisation

```bash
cargo build
cargo test
